# 开源版本的过滤能力

本项目保留普通 DNS 规则过滤、自定义规则、DNS 重写、安全搜索和防沉迷服务管理。

## 固定停用的第三方分类功能

以下两项能力在本开源版本中固定停用：

- `parental`：成人网站分类拦截。
- `safebrowsing`：恶意/钓鱼网站分类拦截。

`internal/filtering/productpolicy.go` 集中定义产品策略。启动时仅初始化保留的过滤能力；过滤执行入口统一遵循策略，旧配置和客户端独立设置中的 `true` 均归一化为 `false`。这两项分类检查器不再发出查询。

全局设置、客户端设置、仪表盘专属计数及图表、日志分类筛选中的对应入口已隐藏。历史日志原因、历史统计字段及兼容实现保留，便于读取旧数据。历史统计可能仍有非零值。

## API 兼容行为

| 接口 | 本版本行为 |
| --- | --- |
| `GET /control/parental/status` | `200`，`{"enabled":false}` |
| `GET /control/safebrowsing/status` | `200`，`{"enabled":false}` |
| 两项功能的 `POST .../disable` | 成功返回，保持停用 |
| 两项功能的 `POST .../enable` | `403`，返回功能已停用的说明 |
| 客户端新增、修改、读取 | 兼容接收旧字段，实际及返回状态为 `false` |

保存配置时保留兼容字段并写入有效的停用状态。旧服务器地址字段可继续被读取，但不用于初始化这两项查询服务。

## 保留功能的边界

普通规则列表仍可按规则拦截成人、恶意或钓鱼域名；本次停用的是专属第三方分类服务，而非按域名内容类别删减规则。安全搜索和防沉迷与这两项分类能力独立。

普通 DNS 上游查询、过滤订阅下载、安全搜索所需解析以及防沉迷目录更新仍按各自设置运行。因此，这项产品策略的范围是停用两项分类查询，而非让整个程序离线。

## 验证

以仓库根目录为工作目录：

```bash
go test -race ./internal/filtering/... ./internal/dnsforward/... ./internal/home ./internal/client
npm --prefix client test
```

集成测试使用本地可计数检查器和确定性数据，验证旧配置、直接请求及客户端独立设置下的分类查询次数为零，同时验证普通规则、安全搜索、防沉迷、API 状态和旧数据转换。
